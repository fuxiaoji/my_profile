# Wenji Fu · Research & Engineering

个人网站：[fuwenji.asia](https://fuwenji.asia)

围绕人工智能、运筹优化和金融科技组织研究与工程实践。保留中英切换、文章、笔记、游戏与影像作品，新增研究索引与公开履历。

## 内容入口

- `/research`：七项研究，按方向筛选，明确区分投稿、预印本和研究稿。
- `/projects`：仿真、多智能体、语言模型、游戏与数据工具。
- `/game`：兵棋工程、状态机、模仿学习、遗传算法及实时视觉。
- `/about`：学习与实践，以及五份公开版 PDF。
- `/writing`、`/study`：文章与学习资料。

## 运行

```sh
npm ci
npm run dev
npm run build
npm run preview
```

静态产物在 `dist/`。React Router 的页面路径需要回退到 `index.html`。已有 API 与媒体目录应在部署时保留。

## 公开资料

公开版简历只保留姓名、学校、经历、研究与项目。手机号、私人邮箱、成绩、推荐信和新头像未放入公开版。旧简历文件的当前版本也已替换为公开版。

GPS 元数据已从相关照片清除，保留显示方向，未重编码图像。构建不输出 source map。提交请使用 GitHub 隐藏邮箱，避免把私人联系方式写入内容或提交记录。

可选本地笔记预览通过 `PORTFOLIO_NOTES_ROOT` 配置；未配置时使用公开笔记索引。请只指定准备公开的资料目录。

研究状态更新于 2026-11-04。评级使用 CCF 2026 和 JCR 2024（2025 发布）；投稿状态不表示录用。
